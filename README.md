# starchasers-android-utils


GM Tools:

 * Home Screen, has various cards which allow the user to load and use the tools below:
 * Dice Roller - select the type (attack or defense) and number, and it rolls them
 * NPC Storage - upload a CSV with NPC stats (Elite, Extra)
 * NPC Generator
 * Ship Generator
 * PC Stat Storage - upload a CSV with PC stats (just for reference and for Turn Tracker below)
 * Combat Turn Tracker
 * Combat Encounter Generator
 * Space Combat Encounter Generator
 * Stealth Encounter Generator
 * Mini Game Runner

So the idea is that the earlier tools feed into the later tools
The Dice Roller is the minimum and is used to roll for PCs and NPCs
NPC storage keeps the Extras and Elites.
The NPC generator generates unique NPCs, like shopkeepers, bystanders, Elites and even Bosses.
